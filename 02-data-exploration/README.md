# 02. Data Exploration

Bagian ini membahas teknik eksplorasi data untuk memahami karakteristik statistik, sebaran fitur, dan distribusi frekuensi variabel sebelum pemodelan.

## Topik dan Studi Kasus

- [`retail-spending-analysis/`](./retail-spending-analysis/): Studi kasus analisis distribusi pengeluaran belanja pelanggan retail, statistik deskriptif kuartil, serta visualisasi histogram dan kurva sebaran frekuensi belanja tahunan (Distribution Plot & KDE).
