# Analisis Pengeluaran Belanja Retail

Eksplorasi data aktivitas belanja pelanggan untuk menganalisis karakteristik statistik, distribusi frekuensi pengeluaran tahunan, dan sebaran variabel transaksi.

## Berkas dan Implementasi
- `analisis_belanja_retail.py`: Skrip mandiri pemrosesan statistik dan visualisasi histogram distribusi data.
- `analisis_belanja_retail.ipynb`: Notebook Jupyter interaktif visualisasi statistik deskriptif dan kurva distribusi frekuensi belanja.

## Variabel yang Dianalisis
1. `durasi_member_bulan`: Lama menjadi anggota aktif (1–48 bulan).
2. `pendapatan_juta`: Estimasi pendapatan bulanan pelanggan (juta IDR).
3. `frekuensi_transaksi`: Rata-rata transaksi belanja per bulan.
4. `total_belanja_juta`: Total akumulasi belanja dalam setahun (juta IDR).
