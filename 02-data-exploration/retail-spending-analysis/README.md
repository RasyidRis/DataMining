# Analisis Belanja Retail

Analisis eksplorasi data (EDA) untuk melihat ringkasan statistik deskriptif dan kurva distribusi frekuensi belanja pelanggan retail.

## Topik Utama
- Ringkasan statistik deskriptif (mean, median, standar deviasi, kuartil).
- Visualisasi bentuk sebaran frekuensi belanja tahunan (Histogram & KDE).

## Berkas
- `analisis_belanja_retail.py`: Skrip mandiri pemrosesan statistik dan visualisasi histogram.
- `analisis_belanja_retail.ipynb`: Notebook eksplorasi interaktif sebaran belanja.
