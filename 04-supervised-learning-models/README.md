# 04. Supervised Learning Models

Pemodelan pembelajaran terarah (supervised learning) yang mencakup tugas regresi dan klasifikasi.

## Topik dan Studi Kasus
- [`regression/laptop-price-estimation/`](./regression/laptop-price-estimation/): Prediksi harga laptop berdasarkan spesifikasi perangkat keras menggunakan Linear Regression (evaluasi R2, MAE, RMSE).
- [`classification/customer-retention-churn/`](./classification/customer-retention-churn/): Prediksi potensi churn pelanggan e-commerce menggunakan Random Forest Classifier (evaluasi Precision, Recall, ROC-AUC, Feature Importance).
