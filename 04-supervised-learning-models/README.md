# 04. Supervised Learning Models

Bagian ini membahas algoritma pembelajaran terarah (supervised learning) yang terbagi menjadi tugas **Regresi** (target kontinu) dan **Klasifikasi** (target diskrit biner).

---

## Topik dan Studi Kasus

### 1. Regression (`regression/`)
- [`laptop-price-estimation/`](./regression/laptop-price-estimation/): Prediksi harga laptop berdasarkan spesifikasi perangkat keras menggunakan Linear Regression beserta metrik evaluasi R2 score, MAE, dan RMSE.

### 2. Classification (`classification/`)
- [`customer-retention-churn/`](./classification/customer-retention-churn/): Klasifikasi potensi churn pelanggan e-commerce menggunakan Random Forest Classifier beserta evaluasi classification report (Precision, Recall, F1-Score), ROC-AUC, dan analisis feature importance.
